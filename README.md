# ❖ VeloBoard - Task Management Web App

VeloBoard is a sleek, responsive Kanban task management application designed to help users efficiently organize projects, track workflows, and visualize task metrics in real time. 

🌐 **Live Demo:** [https://veloboard-4f4f7.web.app](https://veloboard-4f4f7.web.app)

---

## 🚀 Features
* **Secure Authentication**: User sign-up and login powered by Firebase Authentication with persistent sessions.
* **Real-time Kanban Boards**: Manage tasks across multiple stages (*To Do*, *In Progress*, *In Review*, *Done*) with drag-and-drop or status updates.
* **Project Management**: Create, switch between, and delete multiple independent projects dynamically stored in Firestore.
* **Advanced Filtering & Search**: Filter tasks by priority (*High*, *Medium*, *Low*) or search titles instantly.
* **Analytics & Reports**: Visual charts powered by Chart.js displaying status distributions and priority metrics.

---

## 🛠️ Tech Stack
* **Frontend**: HTML5, Vanilla JavaScript (ES6 Modules), CSS3
* **Backend & Database**: Firebase Authentication & Cloud Firestore
* **Visualizations**: Chart.js
* **Hosting**: Firebase Hosting
